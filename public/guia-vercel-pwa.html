1 La idea: tu app corriendo en internet

Hasta ahora Prism AI vivía en tu PC: había que instalar Node y ejecutar npm run dev cada vez. La solución es desplegarlo en Vercel, la empresa que crea Next.js (la tecnología de la app). Vercel compila y sirve tu aplicación en sus servidores 24/7 y gratis para uso personal, y te da un enlace permanente (no caduca en 72 horas como otros servicios). Ese enlace se abre desde cualquier dispositivo y se instala como PWA con su propio icono.

2 Arreglar el workflow de GitHub Actions (el error)

El archivo .github/workflows/ci.yml que subiste ejecutaba una comprobación de código (CI) en cada cambio. Fallaba porque el paso «Lint» usaba reglas de análisis que cambian de versión entre instalaciones, y pasos de más (Prisma y lint por separado) que solo añaden puntos de fallo. Ya está corregido: la versión de abajo solo hace lo importante — instalar y compilar con Node 22 — y además se puede relanzar a mano desde GitHub.

name: CI
on:
  push:
    branches: [main, master]
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: |
          npm install --no-fund --no-audit
          npm run build
        env:
          DATABASE_URL: file:./db/ci.db
          NEXT_TELEMETRY_DISABLED: 1

Cómo aplicarlo (opción A — directo en la web de GitHub, la más fácil):

  1. Abre github.com/TU-USUARIO/TU-REPO.
  2. Entra a la carpeta .github → workflows y pulsa sobre ci.yml.
  3. Pulsa el icono del lápiz (Edit in place). Si no ves el archivo: Add file → Create new file y escribe como nombre .github/workflows/ci.yml.
  4. Borra todo el contenido, pega el YAML copiado y pulsa Commit changes (dos veces: confirmar mensaje y confirmar).

Comprobar que queda verde: pestaña Actions de tu repo → espera 2-4 minutos → debe aparecer ✓ CI en verde. Si quieres relanzarlo sin cambiar nada: entra al run → Re-run all jobs, o usa el botón Run workflow (lo activé en el YAML nuevo).

¿Te dio error 403 o 422 al guardar el workflow? Tu token de subida no tiene permiso para tocar archivos de Actions. Crea el token de nuevo marcando también la casilla workflow (token clásico) o el permiso Workflows: Read and write (fine-grained). La guía de instalación, paso 5, lo explica.
¿No te importa el CI? También puedes borrar el archivo ci.yml desde GitHub (lápiz → los tres puntos → Delete file) y listo: Actions dejará de ejecutarse. Vercel no depende de Actions para funcionar.

3 Dejar tu repo al día con el paquete v2.6.1

Preparé el paquete prism-ai-v2.6.1 con todo corregido: el workflow nuevo, el script de build mejorado (ahora genera el cliente de base de datos automáticamente, algo que Vercel agradece) y el actualizador de GitHub que ya no se come archivos ocultos importantes como .github/ o .env.example. Si tu repo ya está en verde tras el paso 2 pero quieres quedar 100% al día, sube este paquete completo.

  1. Descarga el zip v2.6.1 (enlace al final de esta guía).
  2. Abre tu subir-github-v3.html (también en los enlaces finales — usa esta versión nueva).
  3. Pega tu token, escribe el mismo nombre de repo que ya tienes, elige el zip y pulsa Subir. Se reemplazan los archivos cambiados en un solo commit.
  4. Vercel (paso 4) detectará el cambio y redesplegará solo.

4 Desplegar en Vercel (sin ejecutar nada)

  1. Entra en vercel.com y pulsa Sign Up → Continue with GitHub → autoriza a Vercel. (Plan Hobby: gratis para uso personal, no pide tarjeta.)
  2. En el panel pulsa Add New… → Project.
  3. En «Import Git Repository» verás tus repos: pulsa Import en el de Prism AI.
  4. Configuración: Framework Preset = Next.js (se detecta solo). Build Command, Output Directory, Install Command: déjalos tal cual. Environment Variables: no añadas ninguna.
  5. Pulsa Deploy y espera 2-3 minutos. Verás fuegos artificiales 🎉 y tu enlace: https://tu-proyecto.vercel.app
Enlace permanente: ese enlace no caduca. Ábrelo en el móvil o en cualquier PC y tendrás Prism AI funcionando al instante — sin Node, sin terminal, sin nada encendido en casa.
Si el deploy fallara (poco habitual): en Settings del proyecto → Build & Output Settings → activa el override de Build Command y pon: 
npx prisma generate && npm run build
y vuelve a hacer Deploy (pestaña Deployments → los tres puntos → Redeploy).

Cambios de configuración de tu app (claves, proveedores) NO se tocan en Vercel: todo vive en cada dispositivo. Vercel solo sirve la aplicación.

5 Instalarla como PWA (icono propio)

Abre tu enlace .vercel.app en el dispositivo e instálala según plataforma:

  1. Abre el enlace en Chrome.
  2. Menú ⋮ → Añadir a pantalla de inicio o Instalar aplicación.
  3. Confirma. Aparece el icono ◆ de Prism AI en tu escritorio, a pantalla completa y sin barra del navegador.
  1. Abre el enlace en Safari (imprescindible, Chrome de iOS no instala PWAs).
  2. Botón Compartir (cuadrado con flecha) → Añadir a pantalla de inicio → Añadir.
  1. Abre el enlace en Chrome o Edge.
  2. Pulsa el icono de instalación ⊕ que aparece en la barra de direcciones (o menú ⋮ → Instalar Prism AI).
  3. Se abre como app de escritorio independiente con su icono y su entrada en el menú de inicio.

6 Primer arranque: clave AiHubMix y modelos gratis

  1. Abre la PWA recién instalada: aparecerá el asistente de primera ejecución.
  2. Pega tu clave de aihubmix.com/apikey (botón «Probar conexión» para validar: dirá cuántos modelos gratis encontró).
  3. Elige un modelo gratis — ahora cada modelo muestra el logo de su marca (GPT, Claude, Gemini, DeepSeek, Kimi…).
  4. Si una cuota gratis se agota, la app conmuta sola a otro proveedor gratis conectado.
  5. Repite este paso en cada dispositivo donde instales la PWA (la clave se guarda solo ahí, nunca en el servidor).

? Problemas frecuentes

Actions sigue en rojo tras cambiar el YAML
Entra en la pestaña Actions → pulsa el run fallido → mira qué paso sale en rojo. Con el YAML nuevo solo existen dos pasos: «Instalar Node 22» e «Instalar dependencias y compilar». Si falla la compilación, pulsa sobre el error y cópiame el texto. Recuerda que puedes relanzar con Run workflow tras corregir. Y no olvides: Vercel funciona aunque Actions esté rojo.
GitHub no me deja guardar ci.yml (403 / 422 «workflow»)
Tu token de subida no tiene permiso para archivos de .github/workflows. Solución: crea otro token en github.com/settings/tokens (clásico) marcando repo Y workflow, o en fine-grained activa Contents y Workflows en «Read and write». Actualiza el token en tu HTML de subida.
El deploy de Vercel falla o la app sale en blanco
1) Mira el log del deploy en Vercel (pestaña Deployments → clic en el deploy → Building). 2) Si menciona Prisma, aplica el Build Command del paso 4. 3) Si la PWA instalada queda en blanco tras una actualización: ciérrala del todo y reábrela; si persiste, en Ajustes del navegador borra datos del sitio (la app usa caché inteligente, pero un cierre completo fuerza la versión nueva).
Mi clave AiHubMix, ¿se sube a GitHub o a Vercel?
No. La clave se escribe dentro de la app (asistente o Ajustes → Proveedores) y se guarda únicamente en el dispositivo (localStorage). El repo y Vercel nunca la ven. Por eso cada dispositivo nuevo debe configurarla una vez.
¿Cuánto cuesta Vercel? ¿Hay límites?
El plan Hobby es gratis para uso personal e incluye ancho de banda y ejecuciones de sobra para un chat personal. No pide tarjeta. Si algún día publishes algo comercial, ahí sí necesitarías el plan Pro.
Quiero mi propio dominio (mi-chat.com)
En Vercel: proyecto → Settings → Domains → Add. Si aún no tienes dominio, cómpralo en cualquier registrador y Vercel te guía para apuntarlo. Es opcional: el enlace .vercel.app funciona igual de bien.
