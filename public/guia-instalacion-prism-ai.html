0 Requisitos (5 min)

Solo necesitas una cosa: Node.js versión 20.9 o superior (es el requisito de Next.js 16, el motor de Prism AI).

node -v

Si el comando no existe o devuelve una versión menor a v20.9.0:

⬇ Descargar Node.js LTS (gratis)

Instala la versión LTS dándole a «Siguiente» en todo (Windows) o con el instalador (macOS). En Linux: sudo apt install nodejs npm o nvm.

✅ Meta del paso: al escribir node -v ves algo como v22.14.0.

1 Conseguir el proyecto (2 min)

Descarga el código fuente de Prism AI v2.6 y descomprímelo en una carpeta fácil, por ejemplo C:\prism-ai (Windows) o ~/prism-ai (Mac/Linux). Evita carpetas con espacios o acentos en la ruta.

⬇ prism-ai-v2.6-codigo-fuente.zip Respaldo (gofile)
⏳ El link del zip caduca a los 3 días. Si ya caducó, pídemelo de nuevo en el chat y te genero otro en segundos. El contenido (164 archivos) es el mismo.

Si ya subiste el proyecto a tu GitHub, también puedes clonarlo (cambia tu-usuario):

git clone https://github.com/tu-usuario/prism-ai.git cd prism-ai
✅ Meta del paso: tienes la carpeta del proyecto con package.json dentro y una terminal abierta EN esa carpeta (clic derecho → «Abrir en terminal», o cd hasta ella).

2 Instalar (una sola vez, 3-5 min)

El proyecto trae un instalador que lo hace todo: valida tu Node, instala las dependencias y prepara el entorno.

Doble clic a setup.bat dentro de la carpeta o escribe en la terminal:

npm run setup

En la terminal, dentro de la carpeta:

chmod +x setup.sh && ./setup.sh

o directamente:

npm run setup

¿Qué hace el instalador? 1) Comprueba tu versión de Node · 2) Ejecuta npm install (descarga ~400 MB de dependencias, solo la primera vez) · 3) Crea tu archivo local .env.local.

💡 Si npm run setup diera error de permisos en Mac/Linux, prueba sudo npm run setup. En Windows, si «npm no se reconoce», reinicia la terminal después de instalar Node.
✅ Meta del paso: el instalador termina mostrando el banner de Prism AI sin errores rojos.

Prism AI funciona solo con modelos gratis. Con una sola clave ya puedes chatear; las demás son opcionales y activan el failover automático (si una se queda sin cuota, salta a otra).

¿Dónde pego las claves? En la app: Ajustes (⚙) → Proveedores → pega la clave en su campo → activa su interruptor → guarda. También te lo pide el asistente de la primera ejecución (paso 4).

✅ Meta del paso: al menos AiHubMix (o Gemini/Groq) con su clave pegada y el interruptor activado.

4 Arrancar la app (1 min, cada vez que la uses)

En la terminal, dentro de la carpeta del proyecto:

npm run dev

Abre http://localhost:3000 en tu navegador. La primera vez se abre un asistente de 3 pasos:

1 · Bienvenida → «Empezar»
2 · Conecta AiHubMix → pega tu sk-… → botón «Probar conexión» (debe decir algo como «408 modelos, 53 gratis») → «Guardar y continuar»
3 · Instalar la app → te enseña el paso 5 de esta guía → «Empezar a chatear»
🛑 Para apagar el servidor: Ctrl + C en la terminal. La terminal debe quedarse abierta mientras uses la app.
✅ Meta del paso: envías tu primer mensaje y responde un modelo gratis.

6 Subir tu proyecto a GitHub (token + opciones exactas)

Tienes dos formas: el archivo subir-github-v3.html (sube carpetas o zips completos) o el botón «GitHub» / «Repos» dentro de Prism AI. Ambas usan el mismo Personal Access Token. Así se crea sin fallar:

Entra en github.com/settings/tokens y sigue exactamente esto:

«Generate new token» → «Generate new token (classic)». Si te pide tu contraseña, ponla.
Note: escribe un nombre, ej. prism-ai.
Expiration: elige 90 days o No expiration (si eliges 90 días, al vencer hay que generar otro).
Marca ☑ repo — es la ÚNICA casilla obligatoria. Se marca el grupo completo (repo:status, public_repo…). Sin esto verás error 404/403 al subir.
Opcional ☑ workflow: márcala solo si quieres que se suba también .github/workflows/ci.yml (la CI que incluye Prism AI v2.6). Recomendado.
Baja al final → «Generate token» → copia el token (ghp_…) inmediatamente: GitHub solo lo muestra esa única vez.

Misma página → «Generate new token» → «Generate new token (fine-grained)»:

Token name: prism-ai · Expiration: 90 días o personalizada.
Resource owner: tu usuario.
Repository access: «All repositories» (o «Only select repositories» y eliges el repo destino).
Permissions → Repository permissions → Contents: «Read and write» — obligatorio (Metadata se pone en Read-only solo).
Opcional → Workflows: «Read and write» (para subir la CI).
«Generate token» → copia (github_pat_…) — solo se muestra una vez.

Dónde usar el token:

Opción A — mi uploader: abre subir-github-v3.html → pega el token en el paso 1 → usuario y nombre del repo (ej. prism-ai) → deja marcado «Crear si no existe» → arrastra el zip o la carpeta → «⚡ Subir rápido». Crea el repo y sube TODO en 1 commit.

Opción B — desde la app: Prism AI → botón «GitHub» de la barra lateral → mismo token → selecciona la carpeta del proyecto → subir por lotes.

Opción C — con git (si lo prefieres):
git init git add . git commit -m "Prism AI v2.6" git branch -M main git remote add origin https://github.com/tu-usuario/prism-ai.git git push -u origin main
(te pedirá usuario y token como contraseña; pega el ghp_…)
🔒 El token queda guardado solo en TU navegador (localStorage) y viaja directo a api.github.com. Nunca lo compartas ni lo subas al repo. Si se filtra: github.com/settings/tokens → Delete y genera otro.
✅ Meta del paso: abres github.com/tu-usuario/prism-ai y ves los 164 archivos.

7 Actualizar después (10 seg)

Los dos métodos comparan lo que ya está en GitHub y solo suben los cambios en 1 commit nuevo:

• Con el uploader: abre el HTML → mismos datos (el token se recuerda) → arrastra la carpeta o el zip actualizado → «Subir rápido». Verás «Nuevos: X · Actualizados: Y · Sin cambios: Z».
• Con la app: botón «Repos» → pega la URL de tu repo → «Corregir» con IA si quieres cambiar algo → «Subir cambios a GitHub».
• Con git: git add . && git commit -m "cambios" && git push

8 Problemas frecuentes y solución

❌ «npm run setup» dice que mi Node es muy viejo / «next requires Node >=20.9»

Instala la LTS de nodejs.org, CIERRA la terminal y abre una nueva. Verifica con node -v.

❌ El puerto 3000 está ocupado
npm run dev -- -p 3001

y abre localhost:3001.

❌ AiHubMix: «accounts that have not been recharged can only try 10 times»

No es un error tuyo: es el límite de pruebas sin saldo. Prism AI hace failover automático a otro modelo gratis conectado. Para evitarlo, conecta también Gemini o Groq (paso 3).

❌ GitHub: «401 Bad credentials»

El token está mal copiado o expiró. Genera otro (paso 6) y pégalo completo, sin espacios.

❌ GitHub: «403» o «Not Found» al crear/subir

Al token le faltó ☑ repo (clásico) o Contents: Read and write (fine-grained). Genera uno nuevo con esa casilla marcada. Si el repo es de otra cuenta, necesitas ser colaborador.

❌ El micrófono no dicta / no se escucha la voz

Usa Chrome o Edge (Safari limita el dictado). Acepta el permiso del micrófono cuando lo pida. La voz de lectura usa la del sistema: revisa el volumen o prueba otro navegador.

❌ Instalé la PWA pero se abre en blanco

El servidor npm run dev debe estar corriendo en la terminal. Ábrelo y recarga la app.
