ℹ️ ¿Por qué es más rápido? 
Esta versión usa la Git Database API de GitHub:
1. Obtiene el árbol actual del repo (1 request)
2. Compara cada archivo local con el del repo (sin request)
3. Sube solo los archivos nuevos/cambiados EN PARALELO (10 a la vez)
4. Crea un solo commit con todos los cambios (3 requests al final)

vs v1 (archivo por archivo, secuencial):
- v1: 2100 requests × 0.5s = 17 minutos
- v2: ~150 requests en paralelo × 0.3s = 3 minutos
🔄 ¿Cómo actualizar el repo después? 
Para futuras actualizaciones, simplemente:
1. Modifica los archivos en tu carpeta (o genera el zip de nuevo)
2. Abre este HTML
3. Selecciona la misma carpeta o el mismo zip
4. Click "Subir rápido"
5. La página detecta automáticamente qué cambió y sube SOLO eso

Si solo cambiaste 5 archivos, solo sube 5. Toma 10 segundos.
