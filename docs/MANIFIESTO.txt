Commit: e429763 «ficha del proyecto, permisos de skills con puerta de riesgo y regresión visible»

Las tres mejoras del análisis de PLAN-EVOLUCION.md (puntos 4, 5 y 6):

  4. FICHA DEL PROYECTO (Project Passport)
     La memoria del mapa se presenta como tarjeta de un vistazo (pila con nº de
     archivos, entrada, núcleo, huérfanas, notas) y el agente la lee ANTES de
     trabajar: entra en el system prompt antes del mapa por archivo.

  5. PERMISOS DE LAS SKILLS
     Antes de instalar, el texto se analiza en local: dominios que manda cargar
     (CDN conocido vs desconocido), claves reales que pide, envíos de datos a
     servidores. Riesgo = instalación en dos pasos con aceptación expresa; el
     permiso queda en la skill, visible en la lista, y viaja al prompt como techo.

  6. REGRESIÓN VISIBLE EN EL SANDBOX
     Cada «Ejecutar» deja una instantánea medida (consola + QA móvil + peso del
     HTML). La pestaña nueva «Regresión» compara con la ejecución anterior:
     errores nuevos, errores arreglados, QA que empeora o mejora y un veredicto
     en una línea. Sin datos de un lado, lo dice.

CÓMO APLICARLO
--------------
Si ya tienes el proyecto clonado de antes del lote 2, sustituye estos archivos
en las mismas rutas (la estructura del ZIP replica la del repo). Después:

  npm install        # solo si vienes de antes de la v3.9
  npm run test       # 642 tests en verde
  npm run dev        # http://localhost:3000

Nada de esto requiere migración de datos: el nuevo campo `permissions` de las
skills se calcula al vuelo para las skills que no lo tengan guardado.
